# Decisiones técnicas

Guardar una decisión por archivo, con identificador y estado propuesto, aprobado o reemplazado.

## Contenido mínimo

1. Contexto y requisito que resuelve.
2. Opciones y compatibilidad comprobada.
3. Decisión y razones.
4. Costos, límites y alternativas descartadas.
5. Comandos o evidencia de verificación.
6. Estado, fecha y revisión.
