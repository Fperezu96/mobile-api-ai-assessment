# Capa móvil

Estructura preparada para WebdriverIO y Appium; todavía sin implementación de escenarios.

- contracts: contratos pequeños de catálogo, autenticación y carrito.
- actions: acciones del negocio que reciben las pantallas de la ejecución.
- screens/android: selectores y comportamiento específico Android.
- screens/ios: selectores y comportamiento específico iOS.

El ciclo de sesión y los reportes pertenecen a infraestructura. No copiar UiSelector o clearApp Android como implementación iOS.
